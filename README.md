# CATIA V5 Large Assembly Profile

CATIA V5 için büyük montaj odaklı, izole kullanıcı profili oluşturan Windows aracı.

Uygulama ve çalıştırma yönergeleri [outputs/README.md](outputs/README.md) içindedir. GitHub'a yüklerken yalnızca bu depo içeriğini paylaşın; oluşturulan CATSettings, lisans dosyaları, CATIA environment dosyaları ve masaüstü kısayolları depo dışında tutulur.

Güvenlik tasarımı için [outputs/SECURITY.md](outputs/SECURITY.md) belgesine bakın.
